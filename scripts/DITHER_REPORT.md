# Dither report — film stills

Generated by `npm run stills` (`scripts/process-stills.ts`). Sources: the twelve YouTube ids in `scripts/stills-manifest.ts`. All comparison sheets are in `screenshots/dither/` (gitignored); regenerate them with `npm run stills -- --sheets`.

## Recommendation

**`bayer8`, 2 tones (base + carolina), working width 320, contrast 1.15, gamma 1.3, normalise on, lossless webp.** These are the script defaults.

Why, against the three questions in the brief:

- **Printed matter vs photographic.** Ordered Bayer is the one that reads as a screen print. The 8x8 matrix gives a visible, regular halftone-like rosette; `bayer4` is the same idea but the pattern is so small that it reads as a crosshatch texture rather than a screen. `floyd` and `atkinson` both read as photographs that have been through a fax machine: convincing, but the grain is organic and the result looks like a newspaper photo, not a print treatment. Since the treated state is the site's identity and the real frame is the reward on hover, the more graphic option is the right one. Atkinson is the most graphic of all (it drops a quarter of the error, so it pushes everything to pure base or pure carolina) but it destroys the two darkest faces (`fdoc`, `omnes-unum`).
- **Flattening the differences between sources.** Two tones flatten hardest. With three tones (`deep` as a midtone) the well-lit sources (`senior-assassin`, `how-does-it-feel`) resolve into large flat fields of deep while the dark ones stay base, and the grid starts to show which films were lit properly again. The 3-tone versions are handsomer frame-by-frame but worse as a set, which is the wrong trade for a grid. `normalise` (histogram stretch) does most of the flattening work; it rescues `how-does-it-feel` (a soft, low-contrast source) and `spaghetti-and-me` (very dark). Gamma 1.3 lifts midtones so faces come out of the base field; at gamma 1.6 the bright frames become solid carolina fields and the identity is gone (see `_exp-bayer8-2tone-gamma1.6.png`).
- **Working width.** 320 gives a 4x4 px dither cell at 1280 wide, which is an exact integer, so every cell is the same size and the pattern is perfectly regular. 480 gives 2.667 px cells, so nearest-neighbour upscaling produces alternating 2 px and 3 px cells and a faint moiré. 640 gives 2 px cells, which at card size (roughly 400-600 px wide) is under one screen pixel per dither cell and the result reads as a smooth photograph, defeating the point. If a full-bleed hero ever needs finer grain, `--work=640` (2 px cells) or `--work=426` (3 px cells) are the integer-friendly options.
- **Encoding.** Lossless and near-lossless webp produce byte-identical files for a two-colour image (3-5 KB each). Lossy at q90 is 25x larger (120-130 KB) and introduces ~1000 off-palette colours. Lossless is the default; the treated set totals 31 KB for eleven files.

Every treated file was checked after the run: each is exactly 1280x720 and contains only `#0b0d0f` and `#4b9cd3`.

## Fallbacks and missing sources

The fetch order is `maxresdefault` -> `sddefault` (640x480) -> `hqdefault` (480x360). `sddefault` was added between the two the brief named because it is a strictly better source when max-res is missing.

| Film | Source used |
|---|---|
| slam | `sddefault` 640x480 (no maxresdefault). The original is upscaled to 1280x720 and is soft. |
| at-last-the-gift | **MISSING.** `LKPT6smWlJo` returns 404 for every thumbnail variant and YouTube's oembed endpoint returns 403, which is the response for a private video (a nonexistent id gives 404). No files were written. The script skips it with a warning rather than substituting a frame. The lead needs to decide what the card shows: a type-only locked variant, or get the client to make the video unlisted. |

All other ten films used `maxresdefault` at 1280x720.

## Letterbox handling

The script trims near-black rows from the top and bottom (mean < 12, max < 56 per row, at most 30% from each edge), then centre-crops to 16:9. Trimmed rows per film: fdoc 173, spaghetti-and-me 254, hard-pills-to-swallow 180, a-newby-cupids-guide 114, senior-assassin 44, slam 204 (the 4:3 sd frame plus in-frame bars), the-tulips 2, everything else 0. So four of the max-res frames were themselves letterboxed to a wider ratio inside 16:9; they are now cropped to the picture.

`discrete-magematics` is pillarboxed left and right (a portrait poster on black), which the script does not trim, because cropping a 2:3 image to 16:9 would keep only a band across its middle.

## Bad sources (for DESIGN_NOTES)

Frames are not substituted. These are flagged so the lead can decide:

- **discrete-magematics** — not a frame at all: a portrait 2:3 poster on a black field. Treated, it becomes a solid carolina rectangle with illegible text in the middle of a base frame. It is the one card that visibly breaks the grid. Options: accept it, ask the club for a frame, or hide the still on this card.
- **slam** — a title card: red "SLAM!" text over a dim frame. Dithers cleanly (the type comes out solid carolina) but it reads as type, not a film frame, and the source is sd resolution.
- **the-tulips** — a title card (script title over a landscape). Dithers well and the landscape carries it, but it is still a title card.
- **silenced** — a real frame, but with an "Official Selection, Argyle Film Festival 2026" laurel baked into the image. It survives the dither legibly. Note that this is a laurel graphic the site's own award system does not control.
- **spaghetti-and-me** — very dark source (face lit by a laptop). After normalise and gamma it reads as a lamp and a face against base; it is the sparsest card but arguably the best-looking one. Usable.
- **fdoc** — face against a busy tree canopy; the foliage grain competes with the face at 320 wide. Usable.
- **at-last-the-gift** — no source at all (see above).
